# Execution evidence

Every transaction below was sent by `python -m agentvax.evidence.run` on Base Sepolia (chain id 84532) and was read back from the chain with a successful receipt before it was written here.

The contracts were deployed with the demo profile, so the delays are short enough to wait for in real time. The L2 delay is 60 seconds, the pressure hold is 120 seconds and the loosening delay is 300 seconds.

The token is MockUSD, a test token with no value. Native amounts are valueless test network funds.

The agent ran with MockLLM, the deterministic rule-based stand-in for a language model (mode mock). These rows show that the plumbing and the contracts work. They say nothing about model quality.
